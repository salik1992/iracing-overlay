Existing · Kapps and Racelab

Plate

Ledger

Column labels and a dotted omit line. The player position is the accent color. Nothing else in the row changes weight.

Original · strong ends

Signal

Original · session title

Docket

Combined · tower, plate, signal

Composite

The session type stays muted and the clock is normal text. Position, the surname trigram, and the gap are the strong figures. The car number sits in a three-digit plate. Stops stay dim, and your row carries an accent tick. Class plates carry the class color, and the class name sits in a full separator lined up with the plate. In the team frame the name replaces the gap as well.
